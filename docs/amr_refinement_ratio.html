Optimal AMR Refinement Radius Scaling

In block-structured AMR with 2:1 refinement, each level halves the grid spacing: dx_l = dx_0 / 2^l. The standard practice is to also halve the refinement radius at each level (each finer level covers half the distance from the puncture). This document derives the mathematically optimal radius ratio from first principles and shows that halving is only optimal for a constant field.

1. Truncation Error of a Finite Difference Stencil

A p-th order finite difference approximation of a derivative has local truncation error given by the Taylor remainder:

ε = C · dxp · f(p+1)(r)

where f(p+1) is the (p+1)-th derivative of the field, and C is a constant depending on the stencil coefficients.

2. Radial Falloff of Evolved Fields

Near a Schwarzschild puncture in isotropic coordinates, the evolved fields have power-law behavior at large distance:

f(r) ~ 1 / rα

The n-th derivative of such a field scales as:

f(n)(r) ~ 1 / rα + n

The relevant values of α for the CCZ4 evolved fields:

For the Brill-Lindquist conformal factor ψ = 1 + M/(2r), the solver field ψ − 1 has α = 1. During evolution, the steepest far-field quantity is the extrinsic curvature K ~ 1/r³ with α = 3.

3. Truncation Error at a Level Boundary

Substituting the power-law derivative into the truncation error formula:

ε(r, dx) ~ dxp / rα + p + 1

On AMR level l, with grid spacing dx_l = dx_0 / 2^l and refinement radius r_l (the outer boundary of level l), the truncation error at the level boundary is:

εl = (dx0 / 2l)p / rlα + p + 1

This is largest at r = r_l (the outer edge), where the grid is coarsest relative to the field structure.

4. Equidistribution: Equal Error at Every Level

The optimal refinement places each level boundary such that no single level is the accuracy bottleneck. This is the equidistribution principle: require εl = εl+1 for all l.

Derivation

Set εl = εl+1:

(dx0 / 2l)p / rlα+p+1 = (dx0 / 2l+1)p / rl+1α+p+1

Cancel dx0 and simplify 2l terms:

2p · rl+1α+p+1 = rlα+p+1

Take the (α+p+1)-th root:

rl / rl+1 = 2p / (α + p + 1) ≡ β

The ratio β between consecutive level radii depends only on the FD order p and the field falloff exponent α. It is independent of the grid spacing, domain size, or puncture mass.

5. Properties of β

Since 0 < p/(α + p + 1) < 1 for all α > 0:

1 < β < 2    for all α > 0

Limiting cases:

  • α → 0 (constant field): β → 2. Halving is optimal. A uniform grid would also work — all levels see the same error regardless of radius.
  • α → ∞ (infinitely steep falloff): β → 1. All resolution should be concentrated at the puncture. Coarser levels are irrelevant.

Halving (β = 2) is only optimal for a constant field. For any field that falls off with distance (α > 0), the optimal ratio is strictly less than 2.

9. Which α to Use?

The global discretization error is dominated by the field with the largest truncation error at each level boundary. For multiple fields with different falloff exponents, the bottleneck shifts with distance:

  • Far field (large r): χ − 1 ~ M/r dominates (α = 1, slowest falloff)
  • Intermediate field: K, Aij ~ 1/r³ may dominate (α = 3)
  • Near field (r ~ M): all fields have comparable gradients

Recommendations:

  • Initial data solver (computing ψ): the evolved field is ψ − 1 ~ M/r, so α = 1, β ≈ 1.68.
  • Evolution: the chi-gradient criterion already handles adaptive refinement during evolution. The radius scaling matters most for the initial mesh.
  • Conservative choice: α = 1 (β ≈ 1.68) ensures the slowest-falling field is well-resolved at all levels. Steeper fields (α = 2, 3) will be over-resolved, which is safe.
Key result: For a 6th-order scheme resolving a 1/r field (conformal factor), the optimal refinement radius ratio is β = 23/4 ≈ 1.68, not 2. Each level's radius should shrink by ~40% (not 50%). This requires ~12 levels instead of ~9 for the same domain coverage, but distributes the truncation error evenly across all levels.

10. Refinement Radius Formula

Combining the optimal ratio with mass-based anchoring (finest radius = C · Mp per puncture), the refinement radius at level k (k = 0 finest, k = n−1 coarsest) is:

rk(p) = C · Mp · βk

where:

  • C ≈ 4 (finest level covers ~4M, well beyond the horizon at r ≈ M/2)
  • Mp = mass of puncture p (unequal masses scale naturally)
  • β = 2p/(α+p+1) (derived from equidistribution)
  • k counts from finest (0) to coarsest (n−1)

A block at distance d from puncture p should be refined to at least level l if d < rn−l(p), where n is the total number of AMR levels.
