3. CCZ4 RHS — Term-by-Term

All evolution equation terms verified against GRChombo CCZ4RHS.impl.hpp, AthenaK (Daszuta 2021), BAM (arXiv:1212.2901). SpEC uses generalized harmonic (no direct variable correspondence). NRPy+/Dendro-GR implement BSSN (Z=0).

3.1 Conformal Factor Convention

Lattice: chi = ψ-4 (fields.h:18). GRChombo: Same. BAM: Same. AthenaK: chi = γ-1/3 (different definition). NRPy+: Supports chi, W, phi. Dendro-GR: chi = W2.

MATCH (Lattice, GRChombo, BAM all use chi = ψ-4)

R1: Production NaN/Inf Check (Critical)

The backend API backend_check_finite_packed() already exists for both CPU and GPU. Tests call it. But main.c never calls it in production. Without runtime NaN checking, a blown-up simulation writes garbage for many steps before detection. Early detection saves hours of wasted GPU time on HPC allocations.

Implementation: Add --nan_check_every N CLI parameter (default 10). Call existing API every N steps. Zero performance impact.

R2: ENO/Minmod Prolongation Fallback (High)

Lattice switched restriction to trilinear specifically because 6th-order Lagrange negative weights caused Gibbs oscillations near punctures. The same problem exists in prolongation — 6th-order Lagrange has negative weights that can produce undershoots near the 1/r singularity in chi.

Implementation: Detect cells where chi < threshold (e.g., 0.1). Fall back to minmod or ENO for those cells. Smooth regions keep 6th-order. The 1D tensor-product structure makes this straightforward.

R3: Test κ1=0.02 (Medium)

AthenaK and BAM default to κ1=0.02, which is 5× less constraint damping than Lattice’s 0.1. With Lattice’s strong KO dissipation (per-field σ, CAKO, CP-BCs), lower κ1 may improve waveform phase accuracy. The parameter already exists — this is a tuning task, not a code change.

R4: Higher-Order Restriction (Medium)

Current setup: 6th-order FD, 6th-order prolongation, 2nd-order restriction. ExaHyPE (arXiv:2504.15814) shows this mismatch introduces O(dx2) error at AMR boundaries. A hybrid approach (high-order in smooth regions, trilinear near punctures) would match AthenaK while preserving robustness near singularities.

R5: 8th-Order FD (Low Priority)

Would roughly double accuracy at same grid spacing, or allow ~20% coarser grids. But requires ghost width 5 (currently 4), which ripples through ghost exchange, boundary conditions, memory layout, and all AMR operations. Large architectural change for incremental benefit over 6th-order (convergence order already ~6.5).
