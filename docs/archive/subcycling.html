The Problem: CFL vs Efficiency

In AMR, each refinement level halves the grid spacing: dxL = dx0 / 2L. The CFL stability condition requires dt ≤ C · dx, so fine levels need proportionally smaller timesteps. Without subcycling, there are two bad options:

OPTION A: GLOBAL FINE DT

Use smallest dt everywhere

  • dt = CFL · dxfinest for all levels
  • Fine levels are happy (CFL satisfied)
  • Coarse levels waste work: taking 2L steps when 1 would suffice
4xwasted coarse-level work (max_level=2)
OPTION B: GLOBAL COARSE DT

Use largest dt everywhere

  • dt = CFL · dxcoarsest for all levels
  • Coarse levels step efficiently
  • Fine levels violate CFL → unstable
CrashCFL violation at fine levels

The Solution: Berger-Oliger Subcycling

Each AMR level uses its own CFL-appropriate timestep: dtL = dt0 / 2L. Fine levels take 2x more sub-steps per coarse step. The recursion pattern:

Subcycling step counts per coarse step Level 0: 1 step at dt (coarsest) Level 1: 2 steps at dt/2 Level 2: 4 steps at dt/4 Level L: 2^L steps at dt/2^L (finest)

The levels are advanced recursively. After a coarse step, the next finer level takes two sub-steps to cover the same time interval:

The recursion is depth-first: advance the coarse level, then recursively subcycle finer levels within each coarse step. This ensures the coarse solution is always available when fine levels need ghost data.

Recursive call pattern (pseudocode) subcycle_level(level, dt_level, t_start): save_old(level) // snapshot for temporal interpolation step_level(level, dt_level) // advance this level by dt_level if level < max_level: subcycle_level(level+1, dt_level/2, t_start) // first sub-step subcycle_level(level+1, dt_level/2, t_start + dt_level/2) // second sub-step restrict(level+1 → level) // fine data overwrites coarse parents enforce_algebraic(level) // det(gambar)=1, tr(Abar)=0

Temporal Interpolation

When a fine block needs ghost data from a coarser neighbor mid-subcycle, the coarse data exists at two times: the saved old state (before the coarse step) and the current state (after the coarse step). We linearly interpolate between them:

Temporal interpolation formula U(t) = (1 - frac) * U_old + frac * U_new where frac = (t - t_old) / (t_new - t_old) Examples during one coarse step [t, t + dt_coarse]: First fine sub-step at t: frac = 0.0 → use U_old Second fine sub-step at t + dt_coarse/2: frac = 0.5 → midpoint average

This interpolation is first-order in time, which is sufficient because the spatial prolongation (4th-order Lagrange) dominates the error budget. The ghost fill happens before the fine level is packed into its per-level meshblock_pack_t, so the fine pack sees already-filled boundary data.

Why save the old state? After the coarse level steps, its fields hold the new state. Without a saved copy of the pre-step state, we cannot interpolate to intermediate times. Only levels that have finer children need fields_old storage — leaf levels at max_level never save.

Per-Level Packing

Unlike the global all-leaves pack used for uniform grids, subcycling builds a per-level pack for each step. Only blocks at the target level are packed, so the CK45/RK4 kernel processes a single refinement level at a time. This keeps the same batch kernel infrastructure while respecting per-level timesteps.

// step_level: build per-level pack, then run the standard CK45 kernel sequence
meshblock_pack_t *pack = mesh_build_level_pack(m, level, p->rk_method);

if (level > 0)
    ghost_fill_from_coarser(m, level, frac);  // temporal interpolation

backend_map_pack(pack, p);
backend_zero_packed(pack, PACK_BUF_SCRATCH);
for (int s = 0; s < 5; s++) {
    backend_ghost_exchange_packed(pack);       // same-level ghosts only
    backend_compute_rhs_packed(pack, p);
    backend_sommerfeld_packed(pack, p);
    backend_update_ck45_packed(pack, CK_A[s], CK_B[s], dt_level);
}
backend_unmap_pack(pack);
meshblock_pack_store(pack, m->blocks);

Data Flow: One Coarse Step (max_level=1)

Walk through a complete coarse step with two AMR levels (level 0 and level 1). The coarse step covers time interval [t, t+dt].

subcycle_level(level=0, dt, t) 1. Save level-0 old state // mesh_save_old_level(m, 0) For each level-0 leaf: memcpy fields → fields_old Now fields_old = state at time t 2. Step level 0 by dt // step_level(m, p, 0, dt, 0.0) Build level-0 pack → CK45 stages → store back Level-0 blocks now at time t + dt 3. First level-1 sub-step // subcycle_level(level=1, dt/2, t) frac = 0.0 (t_start = t = coarse old time) ghost_fill_from_coarser: U_ghost = (1-0) * U_old + 0 * U_new = U_old Build level-1 pack → CK45 stages → store back Level-1 blocks now at time t + dt/2 4. Second level-1 sub-step // subcycle_level(level=1, dt/2, t + dt/2) frac = 0.5 (midway through coarse step) ghost_fill_from_coarser: U_ghost = 0.5 * U_old + 0.5 * U_new = midpoint average Build level-1 pack → CK45 stages → store back Level-1 blocks now at time t + dt 5. Restrict level 1 → level 0 // restrict_level_to_parents(m, 1) Volume-weighted fine averaging overwrites coarse-parent cells Ensures coarse-fine consistency at level boundary 6. Enforce algebraic constraints // enforce_algebraic per block det(gambar) = 1, tr(Abar) = 0, chi > 0, lapse > 0
Key ordering detail: The coarse level steps first, before the fine sub-steps. This is the Berger-Oliger "coarse-first" strategy. The coarse solution at t+dt is available throughout the fine sub-steps, enabling temporal interpolation. The final restriction step (fine → coarse) then corrects the coarse solution with higher-resolution data from the fine level.
