Architecture Overview

The N-body BH tracker provides multi-BH diagnostics for N≥2 puncture simulations:

  • Position tracking: Successive lapse-minimum search with exclusion zones (R = 2M per BH). O(N × blocks) per step.
  • AH finding: Per-BH apparent horizon finder (hyperbolic flow) for mass/spin/area extraction.
  • Merger detection: Pairwise distance check: sep < 3 × max(Mi, Mj) triggers merger. O(N²) but N ≤ 32.
  • CSV output: Dynamic columns: 5 global + 6×N per-BH + 1 merger count.
