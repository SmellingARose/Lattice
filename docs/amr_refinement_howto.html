AMR Refinement — How It Works

How Lattice decides where to add resolution around black holes.
See also: mathematical derivation of beta=1.516

The Idea

Black holes have steep gradients — curvature falls off as 1/r³. We need fine grid cells near the puncture and coarse cells far away. AMR (Adaptive Mesh Refinement) achieves this by nesting progressively smaller, finer boxes around each black hole.

Nested refinement boxes around a binary. Coarse levels (1-8) cover both BHs; fine levels (9-11) wrap each puncture individually.

The Radius Formula

Each level's refinement radius is set by physics, not the grid spacing:

rk = C · M · β(levels_from_finest)
C = 4 (finest level covers 4M around puncture)  |  M = puncture mass  |  β = 23/5 ≈ 1.516

β = 1.516 is derived from equalizing truncation error at every level boundary for 6th-order finite differences on 1/r³ curvature fields. Full derivation here.

Step by Step

1

Cap useless levels

If the coarsest refinement radius would exceed the domain half-size (S = L/2), cap the number of levels. Prevents wasting work refining the entire domain uniformly.

2

Compute radius for this level

For each puncture: r = 4 × M_puncture × 1.516^(levels_from_finest). Heavier BHs get larger radii automatically.

3

Find blocks within radius

Loop over every leaf block at the current level. Compute the minimum distance from each puncture to the block's bounding box (AABB-point distance). If a puncture is inside the block, distance = 0.

4

Flag and split

If distance < r_refine, flag the block. Then split every flagged block into 8 children (oct-tree refinement). Each child has half the grid spacing.

5

Rebuild and repeat

Compact the mesh, rebuild neighbor connectivity, then move to the next level and repeat with a smaller radius and finer blocks.

The Distance Check

We use AABB-point distance (minimum distance from the puncture to the block's axis-aligned bounding box), not center-to-center distance. This matters for large blocks where the puncture might be inside or touching the edge.

AABB-point distance: clamp puncture position to the block bounds, then measure Euclidean distance. Puncture inside block = distance 0.

Unequal Masses

The radius is per-puncture, scaled by each BH's mass. A 10M black hole gets refinement regions 10x larger than a 1M black hole at every level. This is automatic — no tuning needed.

A 10:1 mass ratio binary. Each puncture's refinement region is proportional to its mass.

Code Reference

/* src/initial_data/relaxation_amr.c — refine_mesh_near_punctures() */

static const double REFINE_BETA = 1.5157165665103982;  /* pow(2.0, 0.6) */
static const double REFINE_C    = 4.0;  /* finest level = 4M */

for (int level = base_level; level < base_level + n_amr_levels; level++) {
    int levels_from_finest = n_amr_levels - 1 - (level - base_level);

    for (each puncture p) {
        double r_refine = REFINE_C * bhs[p].mass
                        * pow(REFINE_BETA, levels_from_finest);

        for (each leaf block at this level) {
            double dist = AABB_point_distance(block, puncture);
            if (dist < r_refine)
                flag_for_refinement(block);  /* split into 8 children */
        }
    }
}
