Schwarzschild Quasi-Normal Mode Ringdown

Purpose: Validate that Lattice correctly reproduces the known quasi-normal mode (QNM) spectrum of a Schwarzschild black hole. This is the standard first physics test for any numerical relativity code — if the gauge ringdown matches the analytically known QNM frequency and damping rate, the CCZ4 evolution equations, finite differencing, boundary conditions, and gauge conditions are all working correctly.

Date: 2026-03-22

1. Physical Setup

A single Schwarzschild black hole (M = 1) is initialized using Brill-Lindquist puncture data on a conformally flat spatial slice. This is not the true Schwarzschild solution in isotropic coordinates — the conformal flatness assumption introduces a constraint-violating perturbation that must be damped by the evolution.

The gauge conditions (1+log slicing for the lapse, Gamma-driver for the shift) drive the solution toward the trumpet representation of Schwarzschild, where the lapse approaches ~0.3 at the puncture. During this gauge adjustment, the spacetime "rings" at the black hole's characteristic quasi-normal mode frequencies — damped oscillations analogous to the ringing of a struck bell.

Quasi-Normal Modes

For a Schwarzschild BH, the fundamental l = 2 QNM has complex frequency (Leaver 1985):

ω = ωR + i ωI = (0.37367 − 0.08896 i) / M

This gives:

QuantityFormulaValue (M=1)
Oscillation frequencyωR0.37367 / M
Damping rateωI0.08896 / M
PeriodT = 2π / ωR16.81 M
Damping timeτ = 1 / ωI11.24 M
e-folding cyclesωR / (2π ωI)0.67

The signal decays by a factor of e every 11.24M, so after ~50M the QNM amplitude is down by ~e−4.4 ≈ 0.012 of the initial value. We need to capture the first 2–4 cycles (t ≈ 40–100M) to measure the frequency and damping accurately.

Why (2,0) and not (2,2)? The initial perturbation from conformally flat data is axisymmetric (no angular momentum, no preferred azimuthal direction). The dominant mode excited is therefore l = 2, m = 0. The (2,2) mode, dominant in binary mergers, should be near zero for a single non-spinning BH.

Evolution Scheme

  • Formulation: CCZ4 (arXiv:1106.2254)
  • Time integrator: Classic RK4 (4 stages)
  • Finite differences: 6th-order centered stencils
  • Dissipation: 6th-order Kreiss-Oliger (σ = 0.3)
  • Gauge: 1+log slicing (c = 2) + Gamma-driver shift (η = 1)
  • Boundary: Constraint-preserving BCs (BAM-style, arXiv:1212.2901)
  • Constraint damping: κ1 = 0.1, κ2 = 0

Measurement Procedure

  1. Evolve from t = 0 to t = 150M, extracting r · Ψ4 (2,0) mode every 0.625M.
  2. Discard transient: Ignore t < 40M (initial gauge adjustment and junk radiation).
  3. Frequency: Find zero crossings of Re(Ψ4(2,0)), compute average half-period, invert to get ωR.
  4. Damping: Find local amplitude peaks of |Re(Ψ4(2,0))|, fit log(amplitude) vs time to extract slope = −ωI.
